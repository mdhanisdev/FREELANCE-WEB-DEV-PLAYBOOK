# PROJECT CHECKLIST [ ONE PAGE · PER CLIENT ]

Run every project against this. Copy it per client, tick as you go.

------------------------------------------------------------------------

## 01 · GET CLIENTS

```text
□ Lead replied to fast + professionally
□ Qualified: real budget · timeline · decision-maker · clear need
□ Discovery call booked (Calendly)
□ Red flags checked (no budget / "simple" / equity-only / vague)
```

## 02 · COMMUNICATION

```text
□ One primary channel agreed for decisions
□ Response-time expectations set
□ Preview-link + weekly-update cadence agreed
```

## 03 · DISCOVERY & REQUIREMENTS

```text
□ Goals + users + success metrics understood
□ Features listed → mapped to tech (07 - TECH STACK / ADDONS)
□ Content owner decided (who provides text/images)
□ Written scope: what's IN and OUT
□ Sitemap / wireframes done
```

## 04 · PRICING & PROPOSAL

```text
□ Estimate done + buffer added
□ Payment structure set (deposit → milestone → final)
□ Proposal sent (scope · price · timeline · terms)
```

## 05 · CONTRACT & LEGAL   ⚠ before any work

```text
□ Contract signed (scope · schedule · revisions · IP-on-full-payment
  · portfolio rights · support terms · kill fee · late fee)
□ DEPOSIT invoiced and CLEARED
```

## 06 · ACCOUNTS & OWNERSHIP

```text
□ Client created (or will own) domain · hosting · DB · Stripe · email
  · analytics · Sentry · API keys · CMS
□ You invited as collaborator (not owner)
□ Secrets stored in a password manager
□ Confirmed: Stripe/payments are the CLIENT's, never yours
```

## 07 · TECH STACK

```text
□ Stack chosen — grab the ( Default ) file per category, or an alternative
□ Feature tools picked from ADDONS only where the client asked
```

## 08 · BUILD & DEV WORKFLOW

```text
□ Private repo + conventional commits
□ Husky + ESLint/Prettier + env validation active
□ CI running on every push
□ Weekly preview deploy shared for review
□ Scope creep logged as PAID change requests
```

## 09 · TESTING & QA

```text
□ Unit/component (Vitest) + e2e (Playwright) pass
□ Lighthouse green · accessibility (axe) checked
□ Cross-browser + responsive (mobile/tablet/desktop)
□ Forms work end-to-end · 404/error pages · no console errors
□ pnpm audit clean
```

## 10 · LAUNCH

```text
□ Build clean · test/example pages + console logs removed
□ Security headers on · error tracking + analytics live
□ DB migrations deployed (db:deploy)
□ Domain live + HTTPS · PROD env vars set · sitemap submitted
□ Live flows tested (forms · payment real card · login)
□ Watched Sentry + uptime 24-48h
```

## 11 · GITHUB & SOURCE CODE HANDOFF   (clean hands)

```text
□ Repo transferred to client's GitHub org
□ Handed over: code · .env values (via password manager) · README · docs
□ Removed yourself as collaborator
□ Rotated any keys that passed through you
□ Kept only a private archive for the warranty window
```

## 12 · DELIVERY & FINAL PAYMENT   ⚠ money first

```text
□ FINAL invoice sent
□ On payment: ALL ownership transferred (domain · hosting · db · Stripe · keys · repo)
□ Delivered docs + client guide + Loom walkthrough
□ WRITTEN sign-off received
□ Warranty window started (14-30 days)
□ Testimonial + referral requested
```

## 13 · MAINTENANCE & ADD-ONS

```text
□ Retainer offered (Basic / Growth / Pro, paid in advance)
□ Add-on features = new mini-proposal + deposit (loop 03→05)
□ Re-invited to accounts for maintenance access
```
