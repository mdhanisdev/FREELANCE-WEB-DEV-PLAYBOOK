# DELIVERY & FINAL PAYMENT [ MONEY FIRST ]
------------------------------------------------------------------------

## OVERVIEW

Delivery has one rule: money first. You send the final invoice, and only
once it clears do you complete the ownership transfer of everything still
pending. Then you deliver docs, a client guide, and a short walkthrough,
and get written sign-off. Your contract says IP transfers on full
payment — so never hand over the last of the ownership while money is
outstanding. This step ends with clean hands: paid, transferred, removed.

------------------------------------------------------------------------

## DELIVERY SEQUENCE

```text
  1. FINAL INVOICE      → send it, wait for it to clear
        │
        ▼  (payment received)
  2. TRANSFER OWNERSHIP → everything still pending
        │
        ▼
  3. DELIVER DOCS       → guide + Loom walkthrough
        │
        ▼
  4. WRITTEN SIGN-OFF   → delivery accepted, in writing
        │
        ▼
  5. WARRANTY STARTS    → 14-30 days free bug fixes
        │
        ▼
  6. TESTIMONIAL + REFERRAL  (ask while they're happy)
```

------------------------------------------------------------------------

## 1. SEND THE FINAL INVOICE

```text
□ Final invoice = total minus deposit(s) already paid
□ Clear line items, due date, payment link
□ Send via Stripe or Wise; confirm funds actually landed
✓ "Payment received" means cleared in your account — not "sent."
```

------------------------------------------------------------------------

## 2. COMPLETE OWNERSHIP TRANSFER (only after payment)

Everything still pending moves to the client now:

```text
□ Domain        → registrar transfer / push to their account
□ Hosting       → Vercel project ownership to their account
□ Database      → their account, you removed
□ Stripe        → their account owns the live keys + payouts
□ API keys      → handed over via password manager, then rotated
□ Repo          → transferred (from step 11, confirm it landed)
```

```text
✗ NEVER complete full ownership transfer with money outstanding.
✓ Contract: IP and ownership transfer ON FULL PAYMENT.
  Until then, the work is licensed for review, not owned.
```

------------------------------------------------------------------------

## 3. DELIVER THE DOCS

```text
□ Technical docs (README, deploy steps, env setup)
□ Plain-language CLIENT GUIDE — how to run their business on it:
    ✓ how to log in / manage content / read orders
    ✓ where analytics and errors live
    ✓ who to contact for what
□ Short Loom walkthrough (5-10 min):
    ✓ tour the live site + admin
    ✓ show the one or two things they'll do most
    ✓ link it in the delivery email; it kills 80% of "how do I..."
```

------------------------------------------------------------------------

## 4. GET WRITTEN SIGN-OFF

```text
□ Send a delivery sign-off doc / email:
    "Delivery accepted as complete. Warranty period begins today,
     ends [date]." 
□ Client replies / signs → you have a dated acceptance on record
✓ This closes the project scope. New requests after this = add-ons.
```

------------------------------------------------------------------------

## 5. START THE WARRANTY WINDOW

```text
□ 14-30 days of free bug fixes (as per contract)
□ Bug = something in the agreed scope that doesn't work.
□ New feature ≠ bug → that's an add-on (see step 13).
□ Keep your archived repo copy until this window closes.
```

------------------------------------------------------------------------

## 6. ASK WHILE THEY'RE HAPPY

```text
□ Testimonial — ask right after sign-off, give them a prompt:
    "What problem did this solve, and what changed for you?"
□ Referral — "Know anyone else who needs something like this?"
✓ The moment of delivery is peak goodwill. Use it.
```

------------------------------------------------------------------------

## CLEAN-HANDS CONFIRMATION CHECKLIST

```text
✓ All money received and cleared
✓ All ownership transferred (domain, hosting, DB, Stripe, keys, repo)
✓ You removed from every client account
✓ Keys that passed through you rotated
✓ Written sign-off on file
→ You are delivered, paid, and no longer liable for their systems.
```
